# Grep 10,000 Chunk 基准

> 日期：2026-08-10
> 环境：macOS 26.5.2 arm64、Python 3.12.13、SQLite 3.53.1

## 数据与方法

- 100 个文档，每个文档 100 个 active Chunk，共 10,000 Chunk。
- 每个 Chunk 约 0.8 KiB，混合中文、Latin、Arabic、Korean 和大小写文本。
- 按文档 generation 分 100 个事务写入。
- 预热一次后执行 100 个不同的 9 字符字面量查询。
- 每个 pattern 命中 100 个 Chunk，接口在第 21 个真实命中停止并返回 Top 20。
- 查询配置：`timeout_ms=1000`、默认不区分大小写。

## 结果

| 指标 | 结果 |
|---|---:|
| 构建耗时 | 2.241 s |
| SQLite 主文件 | 62.16 MiB |
| Warm P50 | 2.36 ms |
| Warm P95 | 3.12 ms |
| 最大查询耗时 | 8.44 ms |
| 超时查询 | 0 / 100 |

## 结论

当前 SQLite FTS5 trigram 实现在首期 10,000 active Chunk 画像下满足 1,000 ms deadline 和
250 ms 受控退出余量。本结果只证明该容量级别，不外推到更大数据集。
