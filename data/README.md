# Dataset

A small reproducible RAG evaluation corpus built from the **PostgreSQL 16
documentation**. Used by `tests/integration/test_postgres_recall.py` to
catch regressions in the retrieval pipeline (splitter, tokenizer, BM25,
RRF, dense embedding).

## Contents

```
data/
 corpus/
    LICENSE         # PostgreSQL License attribution
    corpus.jsonl    # 21 curated pages from postgresql.org/docs/16
    chunks.jsonl    # gitignored, regenerated by build_dataset.py
 eval/
    golden.jsonl    # 35 hand-written golden queries
```

## Source and licence

- Source: `https://www.postgresql.org/docs/16/`
- Licence: PostgreSQL License (BSD-style permissive); see `corpus/LICENSE`
- 21 pages, ~78 KB cleaned text, 280 chunks after splitting

The corpus is curated by `scripts/fetch_postgres_corpus.py`. Pages with
less than 200 characters of extracted text are skipped automatically.

## Rebuild from scratch

```bash
# 1. Re-fetch + clean the source pages (network required)
python scripts/fetch_postgres_corpus.py

# 2. Chunk the corpus through the project's RecursiveSplitter
python scripts/build_dataset.py
```

Both scripts are idempotent and overwrite their output files.

## Run the recall test

```bash
.venv/bin/pytest tests/integration/test_postgres_recall.py -v
```

Current numbers on `mac-local`:

| Setup | recall@5 |
|---|---|
| hybrid (dense + BM25 + RRF) | 94.29 % |
| dense-only | 65.71 % |
| sparse-only | 100.00 % |

The ablation tests assert that disabling BM25 drops recall below 80 %
so the regression signal stays real as the pipeline evolves.

## Add a golden query

Append a JSON line to `eval/golden.jsonl`:

```json
{
    "query": "natural-language question",
    "expected_section_ids": ["section-id"],
    "expected_keywords": ["token", "token"],
    "min_relevant": 1
}
```

- `expected_section_ids` — one or more `section_id` values from
  `corpus.jsonl`. The query is considered answered if at least
  `min_relevant` of the top-K retrieved chunks come from any listed
  section.
- `expected_keywords` — informational; not currently asserted.
- `min_relevant` — defaults to 1.

After editing, re-run the recall test. If a new query fails, look at
the printed top sections to decide whether the query is genuinely hard
(adjust expectations) or whether the pipeline needs attention.
